# Part 3: Install Jenkins on Ubuntu EC2 Instance (Kubernetes & Rancher Setup)

Follow these steps carefully to install Jenkins and set up your CI/CD pipeline on an **Ubuntu EC2 instance** (already configured from Part 2 with Kubernetes & Rancher).

---

## ✅ Step 1: Update System Packages

```bash
sudo apt update
sudo apt upgrade -y
```

---

## ✅ Step 2: Install Java (OpenJDK 17)

```bash
sudo apt install fontconfig openjdk-17-jre -y
```

Verify Java installation:

```bash
java -version
```

Sample output:

```
openjdk version "17.0.13" 2024-10-15
OpenJDK Runtime Environment (build 17.0.13+11-Debian-2)
OpenJDK 64-Bit Server VM (build 17.0.13+11-Debian-2, mixed mode, sharing)
```

---

## ✅ Step 3: Add Jenkins Repository and Key

```bash
sudo wget -O /usr/share/keyrings/jenkins-keyring.asc \
  https://pkg.jenkins.io/debian-stable/jenkins.io-2023.key

echo "deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc] \
  https://pkg.jenkins.io/debian-stable binary/" | sudo tee \
  /etc/apt/sources.list.d/jenkins.list > /dev/null

sudo apt-get update
```

---

## ✅ Step 4: Install Jenkins

```bash
sudo apt install jenkins -y
```

---

## ✅ Step 5: Start and Enable Jenkins Service

```bash
sudo systemctl enable jenkins
sudo systemctl start jenkins
sudo systemctl status jenkins
```

---

## ✅ Step 6: Allow Jenkins Port on Security Group

Ensure your EC2 security group allows inbound access on port `8080`. If you haven't already done this:

- Go to AWS EC2 Dashboard
- Select your EC2 instance's security group
- Add inbound rule allowing port `8080` from source `0.0.0.0/0`

![Jenkin Running 8080](images/Check-Jenkin-running.png)

---

## ✅ Step 7: Access Jenkins Dashboard

Visit your Jenkins dashboard at:

```
http://<Your-EC2-Public-IP>:8080
```

Retrieve the initial admin password using:

```bash
sudo cat /var/lib/jenkins/secrets/initialAdminPassword
```

Paste the retrieved password into the Jenkins dashboard to continue the setup.

---

## ✅ Step 8: Configure Jenkins User and Plugins

Follow the Jenkins web interface instructions:

- Install suggested plugins
- Create your Jenkins admin user and password

![Jenkin](images/Install-plugins.png)

---

## ✅ Step 9: Install Required Jenkins Plugins

From Jenkins Dashboard:

1. Go to **Manage Jenkins** → **Manage Plugins**.
2. Install:
   - **Docker Pipeline**
   - **Kubernetes**
   - **Git**

---

## ✅ Step 10: Install Docker and Allow Jenkins to Use Docker

```bash
sudo apt update
sudo apt install docker.io -y
sudo systemctl start docker
sudo systemctl enable docker
sudo usermod -aG docker jenkins
```

Verify Docker:

```bash
sudo docker run hello-world
```

Check Jenkins Docker group:

```bash
groups jenkins
```

Should output:

```
jenkins : jenkins docker
```

**Reboot to apply group changes:**

```bash
sudo reboot
```

Reconnect:

```bash
ssh -i /path/to/key.pem ubuntu@<your-ec2-ip>
```

---

## ✅ Step 11: Setting up DockerHub and Kubernetes Credentials in Jenkins

### **1. DockerHub Credentials:**

- Go to **Manage Jenkins** → **Manage Credentials** → **Add Credentials**.
- Select **Username with password**, input DockerHub username and password.
- Save with ID like `docker-pass`.

![Docker Credentials Placeholder](images/docker-credentials-placeholder.png)

### **2. Kubernetes KubeConfig Credentials:**

- Obtain `~/.kube/config` file from Kubernetes cluster (via Rancher or local).
- In Jenkins, add **Secret file** credential and upload kubeconfig file.
- Save with ID like `kubeconfig-id`.

![KubeConfig Placeholder](images/kubeconfig-credentials-placeholder.png)

---

## ✅ Step 12: Create Jenkins Pipeline Job

1. Go to **Jenkins Dashboard** → **New Item** → Select **Pipeline**.
2. **Name** your job and click OK.

![Create Pipeline Placeholder](images/create-pipeline-placeholder.png)

---

## ✅ Step 13: Configure Pipeline Job

### GitHub Repository Setup:

- Check **GitHub Project** and add repo URL.
- **Pipeline script from SCM**:
  - SCM: Git
  - Repository URL
  - Add GitHub credentials
  - Branch: `main`
  - Script Path: `Jenkinsfile`

![GitHub Repo Placeholder](images/github-repo-placeholder.png)

### Polling:

- Check **Poll SCM**, input `* * * * *` for every minute check.

![Poll SCM Placeholder](images/poll-scm-placeholder.png)

## ✅ Step 14: Jenkinsfile Example

```groovy
pipeline {
    agent any

    environment {
        DOCKER_CREDS = credentials('docker-pass')
        DOCKER_REPO = "ranaalshehri/swe645-hw2-student-survey-amd64"
        WAR_OUTPUT = "target/SWE645_HW2_StudentSurvey.war"
    }

    stages {
        stage('Checkout') {
            steps {
                checkout scm
            }
        }

        stage('Build WAR') {
            steps {
                sh "mvn clean package"
                sh "ls -lh ${WAR_OUTPUT}"
            }
        }

        stage('Build Docker Image') {
            steps {
                script {
                    sh "docker build -t ${DOCKER_REPO}:latest ."
                }
            }
        }

        stage('Push Docker Image') {
            steps {
                script {
                    sh """
                    docker login -u $DOCKER_CREDS_USR -p $DOCKER_CREDS_PSW
                    docker push ${DOCKER_REPO}:latest
                    """
                }
            }
        }
    }

    post {
        always {
            echo 'Cleaning up workspace...'
        }
        success {
            echo 'Docker image built and pushed successfully.'
        }
        failure {
            echo 'Build failed. Check the console output.'
        }
    }
}
```

---

## ✅ Step 15: Run the Pipeline

- Go to Jenkins Dashboard → Select Pipeline → Click **Build Now**.
